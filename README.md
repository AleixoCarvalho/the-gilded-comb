# The Gilded Comb ✂

A modern barbershop website with an online haircut booking feature.

- Services menu, barber profiles and an animated gold-and-charcoal design
- Booking form: name, phone, email, service, barber, date, time slot and notes
- Live appointment summary, booking reference and a "My bookings" list with cancel

Built as a single static `index.html` and hosted on GitHub Pages.

> Note: bookings are saved in the visitor's browser (localStorage). To receive bookings centrally, connect the form to a backend or a form service.
